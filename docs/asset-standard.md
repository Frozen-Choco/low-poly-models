# ジオラマ用アセットの制作基準

## 名前

- 表示名は「踏切」「バケツ」「段ボール箱」のように、短く親しみのある一般名を基本とする。
- 素材、寸法、構造、機能、状態は名前に詰め込まず、説明や仕様に記載する。
- 区別が必要な場合だけ最小限の語を加え、同名の別モデルが生じないことを確認する。
- カタログ、アセットのメタデータ、README、生成スクリプトの表示名を揃える。IDとファイルパスは表示名の変更だけでは変えない。

## 見た目

「軽量だが、実物として見て不自然ではない」を基準にする。面数を最小化すること自体を目標にしない。

- 丸い輪郭には必要な分割数を使う。カップ、車輪、支柱、レンズなどは、通常表示と接写の両方で角が目立たないか確認する。
- スムーズシェーディングは陰影の改善に使う。輪郭の角張りは面数を増やして解消する。
- 平面、角、継ぎ目は適切に保持する。全面を一律に丸めない。
- カップの飲み口・空洞・取っ手など、用途から自然に期待される構造を省略しすぎない。
- 物が小さいことを、曲面を粗くする理由にしない。使用画面上での大きさを考慮する。

## 質感

- 陶器・木材・塗装金属・素地金属・樹脂・ゴムを、色だけでなく粗さ、金属度、コーティングの反射で区別する。
- 陶器は釉薬の艶、木材は落ち着いた半艶、塗装面は金属素地と違う反射、ゴムは低光沢を基本とする。
- 樹脂や陶器を金属度だけで光らせない。必要以上に鏡面化して玩具のようにしない。
- 高解像度テクスチャの量で品質を稼がない。必要なら小さいテクスチャを使い、GLBへの同梱と表示確認を行う。
- Blender専用の見た目だけに依存せず、GLBに保存されたPBR材質も確認する。表示アプリの照明・材質拡張対応により見え方は異なる。

## 日本向けの扱い

- 日本にある日用品・家具・道路設備は、日本で見られる配色、形状、仕様を参考にする。
- 日本に唯一の統一デザインがあるとは扱わない。地域・時代・用途の違いを必要に応じて記録する。
- 道路設備などはメーカーや公的資料で確認できる形状・寸法・配色を参考にし、特定製品の忠実な複製や安全規格への適合をうたわない。
- 信号機の今回の基準は支柱との明度差を抑えたライトグレー筐体、艶を抑えた支柱、見分けられるLED配列と点灯／消灯状態。金属だからという理由で強く光らせない。
- 実物を製造・設置するためのモデルではない。

## データと検証

- 1ファイル100,000,000バイト未満。小物はできる限り数MB以下に抑える。
- メートル単位。設置しやすい原点、意味のある部品名、同梱マテリアルを設定する。
- GLB、編集用Blend、確認画像、寸法・三角形数・容量のメタデータを用意する。
- 全体の表裏に加え、曲面が目立つ箇所は接写する。
- 保存後の再読込、面積ゼロの三角形、数値異常、外接範囲、ファイルサイズを検証する。
- 公開後はGit blobのハッシュを制作側と比較し、転送された内容の一致を確認する。

## 独立レビューの必須条件：実物と使い方

制作担当と異なるレビュアーが、制作側の説明だけに依存せず実物資料を調査する。見た目とメッシュ検証だけでは承認しない。

1. 原則としてメーカー公式写真・製品図・取扱説明書・公的資料を確認し、参照URLと対象仕様を記録する。重要な裏面や機構が見えない場合、別角度や別資料で補う。資料不足の部分は推定と明記し、機能上重要な不確実性が残れば保留する。
2. 部品間の向き、回転軸、取り付け位置、開口、肉厚、支持面、空洞と接触関係を実物に照らして比較する。異なる機種の都合のよい特徴を混ぜない。
3. 想定する使い方・組立・設置を具体的に検証する。やかんは把持・傾ける方向・注ぎ口・取っ手の回転軸・蓋の保持と開閉、コーンは底の開口・肉厚・積み重ねの接触と隙間など。必要なら実際にポーズや複製配置を作り、断面・底面・干渉を確認する。
4. メッシュが正常、見栄えがよい、参考画像に似ているという理由で機能上の矛盾を許容しない。一般的な実物で成立する用途を失う欠陥を「非対応」の注記だけで合格にしない。
5. 保存したGLBとBlendの双方を対象に、正面・側面・背面・裏面・接写と実配置を確認する。材質は複数照明で確認し、実物資料と照合する。
6. レビュー記録には実物で確認した事実、モデルとの対応、推定・未検証事項、使用検証結果、修正点を残す。合格は対象ファイルのハッシュ・容量・パスに結び付け、変更後は再レビューする。
7. 公開後に不備が見つかった場合は該当承認を見直し、修正を新規追加より優先する。公開済みという理由で正しさを前提にしない。

これは作画・ジオラマ用の形状整合性確認であり、製造安全性、荷重、耐熱性などの工学認証ではない。


## 確認画像の統一基準

- 新規・更新する現行モデル写真は preview_standard_v1 の共通条件を使う。1,200×1,200、JPEG品質95、固定の色管理・露出・背景・照明を使用し、材質の明暗差を平均化しない。
- 全体像は投影範囲を画面の80%へ収める。表示上の大きさ合わせであり、モデルの寸法・材質を変更しない。接写は対象部位を明記し、実際に拡大する。
- 正面・背面・側面・裏面・接写と互換エイリアスを同時に更新し、古い材質や異なる撮影条件の画像を同じモデルの現行画像に残さない。
- 詳細設定、再現手順、画像の出典ハッシュは [共通撮影パイプライン](../generators/preview_standard_v1/README.md) に記録する。公開済み画像の移行状況は photography-rollout.json を参照する。
- 比較用の旧版画像や機構検証の履歴は、現行の商品写真と区別して保持する。
