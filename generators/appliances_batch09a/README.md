# Home appliances

Two original generic Japanese diorama assets: 冷蔵庫 and 洗濯機. One editable Blender file and one animated GLB each, with 14 canonical JPGs per asset. No brand marks, external textures, generated reference imagery or electrical/safety certification claims. Final source-package acceptance is recorded in reviews/large_appliances_integration/source_package_approval.json.

## Files and reproduction

Delivered assets are under assets/appliances. Source, reference URLs, attachment graph, saved validation and independent review are under generators/appliances_batch09a. Earlier drafts, reference downloads, raw PNGs and extra proof Blends are excluded. Exact delivered hashes are in each metadata.json and reviews/large_appliances_integration/source_manifest.json.

Run `OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 blender -b -t 2 --python-exit-code 1 --python generators/appliances_batch09a/scripts/build_assets.py` from the package root with Blender 4.3.2; its outputs go into the generator folder's assets directory, without replacing delivered files. Each model has a rigid hinge animation: closed at frame 1, open at 61–91, closed at 151. Unlit controls and thermal/electrical/latch functions are illustrative only.

The immutable photography core is in generators/appliances_batch09a_preview_standard_v1. From the package root, render a closed hero with `SOURCE_ROOT="$PWD" OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 blender -b -t 2 --python-exit-code 1 --python generators/appliances_batch09a_preview_standard_v1/render.py -- refrigerator preview`. Open images use evidence-only frame 61 GLBs derived by prepare_poses.py from the exact delivered animated model; these extra GLBs are intentionally excluded from the lean release. Regenerate them from the package root with `OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 blender -b -t 2 --python-exit-code 1 --python generators/appliances_batch09a/scripts/prepare_poses.py`. Then render an open hero with `SOURCE_ROOT="$PWD" OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 blender -b -t 2 --python-exit-code 1 --python generators/appliances_batch09a_preview_standard_v1/render.py -- refrigerator_open open`. Use washing_machine or washing_machine_open for the washer. The interior view uses the corresponding open ID. Original production records are preserved; relocation.json maps exact images and sources into this package. Do not change shared lighting, exposure, resolution, materials or sampling.
