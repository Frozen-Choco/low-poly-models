# Kitchen utensils

Three original unbranded diorama assets. One editable Blend and one GLB per object; canonical JPGs, source, configuration, bounded geometry evidence and immutable photography records.  Independent package acceptance is recorded in reviews/reviewed_eight/kitchen_package_acceptance.json.

## Reproduce geometry safely

Blender4.3.2 with NumPy/SciPy/Pillow. From repository root:

    OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 blender -b -t 2 --python generators/kitchen_batch07a/scripts/build_assets.py -- stainless_ladle
    blender -b -t 2 --python generators/kitchen_batch07a/scripts/validate_saved.py

Omit the asset argument to generate all three. Output goes to generators/kitchen_batch07a/assets/SLUG, separately from delivered assets/kitchen/SLUG. The validator reloads regenerated outputs; it does not replace delivered files. Original packed grain raster is regenerated by the source; no external image texture is required.

## Reproduce photography

    SOURCE_ROOT=$PWD blender -b -t 2 --python generators/kitchen_preview_standard_v1/render.py -- stainless_ladle preview

Use listed asset IDs and views. Renderer/settings remain byte-identical to the published common standard. It outputs to its own repo/assets/kitchen subtree, not over the delivered photographs. Original records retain their actual production paths; relocation.json maps them to identical packaged model/photo bytes. No light, material, quality or exposure override is permitted.

Reference downloads, raw render PNGs, diagnostic galleries, intermediate models and duplicate proof Blends are excluded. Reference URLs and material/dimension assumptions are in generators/kitchen_batch07a/REFERENCES_AND_DESIGN.md. Independent evidence retains historical workspace paths as provenance, not as directly runnable package paths. These are static visual diorama assets, not certified manufactured utensils.
