# くし

丸い歯先と実際の歯間を持つ、粗歯のくしです。オリジナルの汎用ジオラマ用モデルで、特定メーカー製品の忠実な複製や実用品の製造用データではありません。

- メートル単位。寸法170×30×3.2mm、底面Z=0、長手方向X、歯先は-Y方向
- 単一メッシュ、43本の歯、42か所の歯間。38,548三角形
- 茶系の非金属樹脂PBR材質。GLBと編集用Blendを同梱
- r3では歯先の曲面分割と陰影を改善し、幅広い平面の法線を明示固定

保存済みGLB・Blendの独立形状検証、生成ソースから再作成したGLBのバイト一致、共通条件の全11画像の独立内容審査は完了しています。公開ファイル一式の厳密な承認と公開統合確認は別工程です。

## 再現

Blender4.3.2で、同梱generators/household_restart_20261017/scripts/build_comb.pyを実行します。

    blender --background --threads 2 --python generators/household_restart_20261017/scripts/build_comb.py

生成先はスクリプトの親ディレクトリを基準とするmodels/comb/です。公開アセットの場所へ直接上書きする処理ではありません。生成前に同じ基準ディレクトリ内にevidence/を用意してください。生成スクリプトは写真撮影を行いません。再生成したBlendは内部パス等でバイトが異なる場合があるため、GLBのバイト一致と区別します。

一次資料、制作上の仮定、検証範囲は同梱comb-design.mdを参照してください。メーカー画像は配布物に含みません。
